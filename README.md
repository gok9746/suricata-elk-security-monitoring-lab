# Suricata + ELK Stack Security Monitoring Lab

This project demonstrates a complete security monitoring pipeline using Suricata IDS and ELK Stack.

## Components

- Suricata (Intrusion Detection System)
- Filebeat (Log forwarding)
- Logstash (Log processing)
- Elasticsearch (Log storage)
- Kibana (Visualization)

## Architecture

Traffic → Suricata → Filebeat → Logstash → Elasticsearch → Kibana

## Features

- Real-time intrusion detection
- Log collection and analysis
- Security monitoring dashboard
- Attack detection visualization
